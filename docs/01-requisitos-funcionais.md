# Requisitos Funcionais

RF01 - O sistema deve autenticar usuários por login e senha, informando erro em caso de dados incorretos.
RF02 - O sistema deve exibir o usuário logado e permitir logout.
RF03 - O sistema deve listar, pesquisar, cadastrar, editar e excluir produtos.
RF04 - O sistema deve validar campos obrigatórios e dados inválidos no cadastro de produtos.
RF05 - O sistema deve registrar entrada e saída de estoque por produto.
RF06 - O sistema deve registrar a data e o responsável de cada movimentação.
RF07 - O sistema deve alertar quando o estoque de um produto ficar abaixo do mínimo configurado.
RF08 - O sistema deve manter um histórico consultável de todas as movimentações.
